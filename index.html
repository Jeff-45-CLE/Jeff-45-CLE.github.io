Lab project / 实验室项目 Dataset / 数据集

RayVerse

A large-scale urban radio propagation dataset generated via ray tracing, containing multipath propagation data and building geometry across 100 urban map scenarios. It supports research on RSS prediction, APS estimation, PDP analysis, and antenna beam pattern evaluation.

RayVerse 是基于光线追踪生成的大规模城市场景无线传播数据集，包含 100 个城市场景下的 多径传播数据与建筑几何信息，可用于 RSS 预测、APS 估计、PDP 分析和天线波束模式评估等研究。

  • Role / 角色：Collaborating Builder, UNIC Lab
  • Focus / 方向：ray tracing dataset, radio propagation, visualization
  • Stack / 技术：Python, propagation data processing
GitHub Repository / 仓库
Lab project / 实验室项目 Code / 代码

D²LoS

A research codebase for the D²LoS pipeline, including model training, inference with geometric correction, propagation-data conversion, and visualization utilities for RSS, APS, and PDP analysis.

D²LoS 是实验室的研究代码仓库，包含模型训练、带几何校正的推理、传播数据转换， 以及面向 RSS、APS、PDP 分析的可视化工具。

  • Role / 角色：Collaborating Builder, UNIC Lab
  • Focus / 方向：AI-guided RT, geometric correction, inference pipeline
  • Stack / 技术：Python, PyTorch, OpenCV

Research method / 研究方法

A practical workflow for AI-guided RT.

面向 AI-guided RT 的实践型研究流程。

01

Start from physics / 从物理模型出发

Clarify the ray tracing model, assumptions, constraints, and measurable objective.

先明确光线追踪模型、假设、约束和可衡量目标。

02

Design guidance / 设计引导策略

Study where AI guidance may improve sampling, search, acceleration, or estimation.

分析 AI 引导可能改进采样、搜索、加速或估计的位置。

03

Measure tradeoffs / 衡量取舍

Compare accuracy, efficiency, stability, and implementation complexity.

比较精度、效率、稳定性和实现复杂度之间的取舍。

04

Make it reproducible / 保持可复现

Turn experiments into clear notes, figures, code, and case studies.

把实验整理成清晰的笔记、图示、代码和案例。
